# GUPZ-testscripts

FHIR TestScript resources and fixtures for conformance testing against the
[open-GUPZ][opengupz] specification. `main` carries this page and the licence;
all TestScripts, fixtures and documentation are on
[`noref-import-nictiz-and-set-up-fsh`][branch], open as [PR #1][pr1], and that
branch is what a test run loads. It merges into `main` once the material has run
against a data platform. CC0 1.0 covers the work produced by GUPZ, not the files
derived from Nictiz material; `UPSTREAM.md` on that branch records which ones.

[opengupz]: https://github.com/Gegevensuitwisseling-Paramedische-Zorg/open-GUPZ
